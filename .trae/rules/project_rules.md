# Rules

## Conversation Rules

When answering my questions, please follow the rules:
1. Please use the system default language to answer my questions.

## Code Edit Rules

When editing the code, please follow the rules:
1. Do not remove any existing comments.
2. Do not add any new comments that are not necessary.
3. Do not change the indentation or spacing of the code.
4. Do not change the functionality of the code.
5. Do not change the code that is not related to the current task.
6. You should follow the code style below.

## Code Style

Common code style:
1. When generating new lines, please trim the end of the line.

Java code style:
1. `@since` should use today (the current time), not from other Java class comments.
